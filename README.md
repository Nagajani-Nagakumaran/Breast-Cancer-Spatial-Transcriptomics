# Spatial Transcriptomic Analysis of Human Breast Cancer

Exploratory spatial transcriptomic analysis of a publicly available
10x Genomics Visium human breast cancer dataset.

## Overview

This project investigates spatial transcriptional heterogeneity within
human breast cancer tissue using R, Seurat and spatial transcriptomic
analysis.

The workflow includes:

- Quality control of Visium spatial transcriptomic data
- SCTransform normalisation
- PCA and UMAP dimensionality reduction
- Graph-based transcriptomic clustering
- Spatial mapping of transcriptional clusters
- Marker-based tumour microenvironment profiling
- Epithelial, immune, myeloid and stromal programme scoring
- Spatially variable gene analysis using Moran's I
- Histopathological exploration in QuPath

## Data

Publicly available 10x Genomics Visium human breast cancer data are used.
Raw data are not included in this repository.
